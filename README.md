# Avatar_creation
AI-avatar for news content creation — NewsAI Studio.

Transform news articles into broadcast news videos with AI presenter avatars and lip synchronization.

## Features
- **Phase 2 — Article Extraction**: Zero-cost readability extraction with editorial parsing.
- **Phase 3 — Research Agent**: Claim verification across web sources using Gemini + Tavily.
- **Phase 4 — Script Generation**: Structured broadcast news scripts with claim traceability.
- **Phase 5 — Voice Synthesis**: High-quality presenter speech with ElevenLabs TTS.
- **Phase 6 — Presenter Avatar**: Talking head video with lip-sync via D-ID (plus mock provider support for development).
- **Client Pipeline Caching**: Browser-side caching for fast restoration without duplicate API consumption.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the studio.
